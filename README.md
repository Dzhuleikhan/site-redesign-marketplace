# site-redesign — каталог плагинов Claude

Плагин **site-redesign**: Claude делает редизайн существующего сайта — новый визуальный язык
при той же структуре страниц и логике. Концепт-макеты с маскотом и артами из Magnific,
затем код главной и всего сайта со сверкой по макету.

## Установка (один раз)

1. Открыть приложение Claude → **Customize → Plugins** (раздел плагинов) → **Add marketplace**.
2. Ввести адрес каталога: `<github-логин>/site-redesign-marketplace`.
3. Установить плагин **site-redesign** из этого каталога.
4. Подключить коннектор **Magnific**, когда Claude предложит, и войти в аккаунт Magnific.

В Claude Code то же самое командами:

```
/plugin marketplace add <github-логин>/site-redesign-marketplace
/plugin install site-redesign@site-redesign-marketplace
```

Обновления приходят сами, когда в этом репозитории поднимается версия плагина.

## Перед первым запуском

- Подключить в Claude папку с репозиторием сайта.
- Запустить dev-сервер сайта.
- Создать ветку под редизайн — git делает человек, Claude коммиты не делает.

## Команды

| Команда | Что делает | Что делаешь ты |
|---|---|---|
| `/redesign-concept` | Спрашивает папку проекта и сайты/папки, на которые нельзя быть похожим; делает 2 варианта макета (тёмная + светлая, модалка входа) | Выбираешь: «делаем вариант N» |
| `/redesign-home` | Переписывает тему, шрифты, хедер, сайдбар, футер, главную и модалки входа; сверяет с макетом | Смотришь сайт, запускаешь typecheck/lint |
| `/redesign-site` | Раскатывает дизайн на остальные страницы, модалки и состояния | Проверяешь, коммитишь, делаешь PR |
| `/redesign-autopilot` | Всё сразу после ответа на вводные; вариант выбирает сам | Смотришь результат в конце |

Ход работы хранится в `.redesign/STATE.md` в корне репозитория сайта — можно продолжить
в новой сессии. Не коммитить (добавить в `.git/info/exclude`).

## Обновление плагина (для владельца репозитория)

1. Поправить файлы в `plugins/site-redesign/`.
2. Поднять `version` в `plugins/site-redesign/.claude-plugin/plugin.json` и в
   `.claude-plugin/marketplace.json`.
3. Закоммитить и запушить.
