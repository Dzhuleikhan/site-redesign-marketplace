# site-redesign

Редизайн существующего сайта: новый визуальный язык при той же структуре страниц и логике.

## Как пользоваться

1. Подключить в Claude папку с репозиторием сайта и запустить dev-сервер.
2. Подключить коннектор **Magnific** (ставится с плагином) — для маскота, артов и иконок.
3. Создать ветку под редизайн — git делает человек.
4. Шаги:
   - `/redesign-concept` — Claude спросит папку проекта и ссылки/папки проектов, на которые
     новый дизайн не должен быть похож, и сделает 2 варианта макета (тёмная + светлая тема,
     модалка входа) на холсте. Выбрать: «делаем вариант N».
   - `/redesign-home` — код темы, шрифтов, хедера, сайдбара, футера, секций главной и модалок
     входа/регистрации со сверкой по макету. Проверить, запустить typecheck/lint.
   - `/redesign-site` — остальные страницы, модалки и состояния.
   - `/redesign-autopilot` — всё одной командой после ответа на вводные; вариант Claude
     выбирает сам.
5. Ход работы хранится в `.redesign/STATE.md` в корне репозитория — можно продолжить в новой
   сессии. Не коммитить (добавить в `.git/info/exclude`).

## Что внутри

- `project-rules` — как найти и соблюдать правила самого репозитория и границы в нём.
- `redesign-playbook` — опись структуры, проверка оригинальности, арты Magnific, перенос
  в код, сверка макета с сайтом, известные ловушки.
- `redesign-concept`, `redesign-home`, `redesign-site`, `redesign-autopilot` — шаги.

## Ограничения

- Claude не делает git-записи и не запускает менеджеры пакетов без просьбы.
- Генерации Magnific расходуют кредиты подключённого аккаунта.
