# Известные ловушки

Собраны на реальном редизайне. Не повторять.

1. **Перекраска вместо редизайна.** Первый результат сохранил форму блоков, типографику,
   декоративные полосы и карточки старого дизайна, поменяв только цвета, — пользователь увидел
   «тот же сайт». Решение: чек-лист `originality.md` применять и к ТЕКУЩЕМУ дизайну проекта,
   не только к референсам.
2. **Структуру меняли в макете.** Макет с переставленными блоками отклонён. Макет строится
   строго по описи.
3. **«Сделал по макету», а не сделал.** Код правили по памяти о макете и пропустили футер,
   нижние кнопки сайдбара, модалки и внутренности секций. Решение — поблочная сверка по
   `verification.md` с артбордом перед глазами.
4. **Светлая тема забыта.** Правки проверяли только в тёмной. Каждый блок — обе темы.
5. **Арты из старой палитры.** Новые цвета + старые арты = чужеродно. Перегенерировать под
   палитру варианта.
6. **Иконки на тёмной подложке** ломают светлую тему — генерировать на прозрачном фоне.
7. **Статика может не отдаваться локально** (часть путей обслуживает CDN/прокси). Картинку,
   которую надо проверить локально, импортировать статически рядом с компонентом.
8. **Глобальная замена строк** задевает кеш сборки (`.next`, `dist`) — менять только файлы
   под git.
9. **Несуществующие переменные/токены** молча ломают отступы и цвета — проверять имя в файле
   токенов перед использованием.
10. **Показ по внешней ссылке (ngrok и т. п.):** dev-сервер Next 16 не пускает чужой origin —
    `allowedDevOrigins` в конфиге (не коммитить); туннель запускать с подменой Host на
    `localhost`; старый service worker на том же домене туннеля может показать другой проект —
    проверять в инкогнито.
11. **Сеть.** Из песочницы доступны не все сайты; проверки ботов (Cloudflare и т. п.) не
    обходить — просить скриншот.
12. **Половинчатая перекраска страниц** (заменили hero, подкрасили остальное) выглядит как
    старый сайт в новых цветах — пользователь это не принимает. Страница переписывается
    целиком по фрейму или не трогается.
13. **Агенты параллельно** — лимит токенов уходит за час. По одному, режим экономии из
    `figma-pipeline.md`.
14. **Код раньше Figma.** Когда главную сверстали до Figma, макет и сайт разъехались, и
    Figma пришлось подгонять под код. Поэтому сначала весь сайт в Figma, потом код.
15. **Скрытая панель встроенного браузера** не догружает ленивые секции — структуру брать из кода.
16. **Те же элементы, что были.** Редизайн меняет вид, а не набор элементов: не добавлять
    хлебные крошки, крестики, кнопки, ссылки, кикеры и тексты, которых не было, и не убирать
    существующие (анимации, стрелки каруселей, липкое меню, скрытые подписи для скринридеров).
    Модалкам не менять режим показа, закрытие и отправку по Enter.
17. **Переводы.** Не заводить новый ключ с тем же текстом, что у существующего: остальные
    языки теряют перевод. Один ключ — один текст по умолчанию во всём коде, иначе экстрактор
    падает на конфликте.
18. **`Trans` с разметкой `<0>…<2>…</2><3></3>…</0>`.** Номера указывают на позиции дочерних
    элементов JSX. Меняя вёрстку, сохранить тот же порядок и число детей (включая `{" "}` и
    `<br />`), иначе слово попадает не в тот элемент — например, в пустой разделитель, и
    текст встаёт вертикально.
19. **Удаление файлов** — только после проверки, что их никто не импортирует (включая
    тесты). Удалили лишнее — сразу падает typecheck.
20. **Тесты, привязанные к виду.** После редизайна обновлять моки картинок, удалённых модулей
    и ожидаемые пути ассетов; в jsdom нет `ResizeObserver`.
21. **Перед PR подтянуть свежую базовую ветку.** В ней может оказаться чужой параллельный
    редизайн тех же экранов; решение «чей дизайн главный» принимает человек, а файлы, влитые
    без конфликтов и рассчитанные на чужие версии компонентов, приводятся к своей версии.
    После мержа перегенерировать клиенты (GraphQL, ORM), иначе падает typecheck бэкенда.
22. **Картинки на стенде.** Свои ассеты класть в `public` приложения; то, что всегда шло с
    CDN бренда, может на стенде отсутствовать — проверять отдельно и не путать с поломкой
    редизайна.
23. **Память tsc.** Большой фронт может не пройти typecheck с лимитом Node 4 ГБ — запускать с
    `NODE_OPTIONS=--max-old-space-size=8192`.
