# Концепт редизайна

Сначала прочитать навык `redesign-playbook`: `SKILL.md`, затем `references/lessons.md`.

## Шаги

0. **Вводные — спросить в самом начале**, одним сообщением (карточкой вопросов, если она
   есть), и ждать ответа. Что уже есть в запросе — не переспрашивать:
   - **проект для редизайна** — подключённая папка репозитория; нет папки — попросить добавить
     её в приложении Claude; адрес запущенного dev-сервера;
   - **на что новый дизайн НЕ должен быть похож** — ссылки на сайты и/или папки проектов
     (их тоже можно подключить). Текущий дизайн самого проекта в этот список входит всегда;
   - **что оставить** из нынешнего дизайна (цвет кнопки, логотип, маскот) и пожелания по
     настроению, если есть;
   - **сколько вариантов** — по умолчанию 2.
   Записать ответы в `.redesign/STATE.md`.
1. **Окружение.** Проверить: папка проекта и папки референсов читаются; есть инструменты
   Magnific; отвечает dev-сервер. Чего нет — сказать одной строкой, что подключить, и
   продолжать с тем, что есть.
2. **Опись структуры** — по `references/structure-inventory.md`. Записать в `.redesign/STATE.md`.
3. **Паспорта** текущего дизайна и каждого референса (ссылки и папки) — по `references/originality.md`.
4. **Языки вариантов.** Для каждого варианта сформулировать 8 измерений так, чтобы правило
   отличия выполнялось против всех паспортов и варианты отличались друг от друга.
   Проверить таблицей ДО рисования; не проходит — менять язык, а не рисовать.
5. **Маскот и арты** — по `references/magnific.md`. Маскот подтверждается у пользователя,
   если он рядом; если нет — выбрать лучший кандидат и написать, почему.
6. **Макеты** — по `references/mockups.md`: на каждый вариант главная (тёмная и светлая) и
   модалка регистрации (тёмная и светлая).
7. **Отдать:** ссылка на холст, таблица оригинальности, по 3–4 строки на вариант,
   вопрос «Какой вариант берём?». Записать варианты и их решения в `.redesign/STATE.md`.

## Точка утверждения

Остановиться и ждать выбора. Доработки варианта по комментариям — на том же холсте.
Код не трогать на этом шаге совсем.

Когда пользователь выбрал («делаем вариант 2», «берём этот») — записать выбор в
`.redesign/STATE.md` и предложить следующий шаг одной строкой: «Рисую весь сайт в Figma?»
(навык `redesign-figma`).
