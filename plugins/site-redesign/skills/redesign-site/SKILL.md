# Раскатка на весь сайт

1. Прочитать `.redesign/STATE.md`; главная должна быть отмечена как утверждённая. Нет —
   спросить, утверждена ли она, и остановиться.
2. Прочитать `project-rules` и из `redesign-playbook`: `lessons.md`, `implementation.md`,
   `verification.md`.
3. **Опись остального**: все страницы из `.redesign/STATE.md` с пометкой «редизайн», все
   модалки и состояния (пустые списки, ошибки, загрузка-скелетоны, тосты, авторизованный
   пользователь против гостя — что можно увидеть локально). Добавить найденное в STATE.
4. **Сначала общее.** Пройти компоненты кита, которые используются на многих страницах
   и ещё не приведены к варианту (таблицы, фильтры, пагинация, формы, табы, пустые состояния,
   хлебные крошки). Одна правка в ките закрывает десятки страниц.
5. **Потом страницы**, группами по разделам (каталог игр, провайдеры, профиль, бонусы,
   рефералы, VIP/ранги, статические, депозит). Для больших объёмов разрешено раздать группы
   отдельным агентам: каждому — ссылка на холст, `.redesign/STATE.md`, правила `project-rules`
   и `redesign-playbook`, его список файлов; агенты не правят кит и общие переменные —
   только свои страницы. Общий слой правит основной исполнитель.
6. Для страниц, которых нет на макете, — выводить вид из языка варианта (те же поверхности,
   заголовки, кнопки, табы, отступы), не изобретать новых приёмов.
7. После каждой группы — сверка по `verification.md`: 1440 и 375, обе темы, + отметка в STATE.
8. Саморевью всего диффа по `project-rules`, отчёт: таблица «страница — статус — расхождения»,
   что не проверено визуально и почему, напоминание про typecheck/lint/тесты.
